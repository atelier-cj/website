# 产品概览

生态里已经跑起来的三个成品：荧的炼金工房、世界树、星痕的炼金工房。三者**都是闭源产品**——本站只做生态展示，不提供源码与构建入口；生态里可以直接用的是 [九个开源库](/libs/)。

## 对照

| | [荧的炼金工房](/products/lumine) | [世界树](/products/yggdrasil) | [星痕的炼金工房](/products/starline) |
|---|---|---|---|
| 一句话 | 原神 AI 配装助手 | 插件化 Agent 宿主 · dsh 的仓颉实现 | 人机共享的常驻桌面 |
| 形态 | Web 界面 + Windows 桌面；同时是一个 MCP 服务 | 宿主进程 + 一组插件进程；Web / 单次 / 交互三入口 | 常驻服务 + 浏览器界面（桌面与手机同一份数据） |
| Agent 的位置 | 应用里的助手：查数据、改配装、答疑 | 宿主里的能力，由插件按 profile 装配提供 | 与人平权的常驻实体：Router + 多 Worker |
| 用户数据 | 本地存档（角色库 / 配装 / 配队 / 会话） | 由会话与工具插件承载，配置随 profile | 本地配置库 + 时序库 + 每面板状态 |
| 当前状态 | 可用 | Phase 1–3 完成，多会话运行面已落地，Phase 4 规划中 | 正在重构（形态已定案） |

## 各自的形状

**荧的炼金工房**是一个业务应用。角色库、武器、圣遗物、配队、多套配装方案都在本地存档里；AI 负责理解「这套配装的元素精通够吗」这类问题，自己决定查哪些数据。它的特别之处是同一个内核有两个出口：浏览器里是给人看的界面，另一侧是给其它 AI 用的 MCP 服务端。

**世界树**是基础设施。它是 **dsh（DeepSeek Harness）的仓颉实现**：形态对齐 dsh 的「一切皆插件」，内核整条换成仓颉。它不提供业务功能，而是把「模型、工具、会话、Agent」各拆成独立插件进程，由一份 profile 声明装配成宿主；同一套二进制能跑成带界面的服务，也能跑成无界面的单次问答。它面向的是「要长期跑、要换组件、要多形态装配」的场景。

**星痕的炼金工房**是长跑形态的探索。桌面由面板组成（聚焦、待办、对话、日志、角色、关系……），人与 LLM 看同一块屏、改同一份数据；Router 常驻协调、Worker 隔离干活。对话只是其中一个面板，不是上下文的主角。

## 三个产品在验证什么

- **荧**验证「把 Agent 塞进一个有真实数据和真实规则的业务应用」：面板计算与词条规则是确定性代码，AI 负责理解意图、组合查询、解释结论。
- **世界树**验证「Agent 的基础设施可以拆可以换」：崩一个插件不影响其它，换一个组件不改主程序，能力可以第三方提供。
- **星痕**验证「Agent 长期在线时，除了聊天框还能长成什么样」：面板摘要化 + 分层时间记忆，让长跑会话不靠裁历史来省 token。

## 共同的底色

- **都构建在 [Atelier](/libs/atelier) 之上**：Agent 循环、工具系统、上下文压缩、会话、信任闸门来自框架层，产品里不复制一份内核。
- **界面都走服务端驱动**：荧的 Web 版与星痕用 cjxt 渲染页面；世界树的宿主界面也是 cjxt。荧的 Windows 桌面版另用原生 GUI 框架，与 Web 版共用同一份业务内核。
- **数据都在本地**：不经第三方服务；调用模型只发必要上下文。
- **都闭源**：产品不进仓颉中心仓，也没有公开的源码地址。

## 共同的取舍

三个产品在各自的形态上都做过明确的减法，这些取舍比功能列表更能说明它们是什么：

| 取舍 | 谁做的 | 理由 |
|---|---|---|
| 不做插件宿主，保持单体 + 分层 | 星痕 | 单用户单机的常驻助手用不上进程隔离/热卸载/多租户，却要付跨进程调用的代价 |
| 不把渠道与部署放进宿主 | 世界树 | 那会让通用宿主退化成「只服务一个产品」，渠道与部署应由产品层决定 |
| 业务内核不依赖界面库 | 荧 | 同一份业务逻辑要同时出现在浏览器与原生窗口里 |
| 长耗时能力走异步任务 | 荧 | 同步调用会阻塞整条连接，用户也拿不到中间反馈 |

## 开源的部分在哪

产品闭源，但它们踩的是同一套公开的库。要动手，从这些页开始：

| 想做什么 | 去哪 |
|---|---|
| 搭一个自己的 Agent | [搭建一个 Agent](/guide/agent-stack) |
| 选协议（MCP / A2A / ACP / UHP） | [协议选型](/guide/protocols) |
| 查某个包怎么用 | [库索引](/libs/) |
| 看整张依赖网 | [生态全景](/ecosystem/) |

换句话说：产品是这套生态的**用法示例**，不是它的全部。九个库都能单独取用——只写一个 MCP 服务器就装 `mcp`，要完整 Agent 就装 `atelier`。
